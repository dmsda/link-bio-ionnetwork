## 🌟 Highlight Showcase Produk & Solusi Digital

## 💻 Cara Menjalankan Secara Lokal (Quickstart)

Proyek ini dibangun tanpa dependensi eksternal yang rumit, sehingga dapat langsung dijalankan setelah di-clone:

```bash
# 1. Clone repository
git clone https://github.com/dmsda/link-bio-ionnetwork.git
cd link-bio-ionnetwork

# 2. Jalankan server lokal
npm start
# atau
node server.js
```

Akses melalui peramban:
* **Halaman Utama (Link in Bio)**: `http://localhost:3000/`
* **Halaman Showcase & Simulator**: `http://localhost:3000/showcase.html`

## ♿ Aksesibilitas & Optimasi SEO

* **Target Sentuh Ergonomis**: Seluruh tombol kartu memiliki tinggi $\ge 50\text{px}$ dengan atribut `aria-label` deskriptif (memenuhi kriteria WCAG 2.1 AA).
* **Safe-Area Insets**: Dilengkapi dukungan `env(safe-area-inset-*)` agar tampilan aman pada layar smartphone berponi (*notch*) atau berlubang (*island*).
* **Schema.org JSON-LD**:
  Metadata entitas organisasi terhubung langsung ke Knowledge Graph Google dan mencakup seluruh tautan media sosial resmi.
* **Social Graph Ready**: Dilengkapi meta tag Open Graph (Facebook, WhatsApp, LinkedIn) dan Twitter Cards beresolusi tinggi (1200x630).

## 🌐 Panduan Deployment (Produksi)

Karena arsitektur proyek ini murni statis dengan server Node.js ringan, Anda dapat mendeploynya ke berbagai platform dalam hitungan detik:

### 1. Vercel
1. Hubungkan repositori GitHub `https://github.com/dmsda/link-bio-ionnetwork` ke dashboard Vercel.
2. Vercel akan otomatis mendeteksi proyek sebagai *Static Site*.
3. Klik **Deploy** — selesai!

### 2. Netlify
1. Pilih **Add new site** > **Import an existing project** dari GitHub.
2. Publish directory: `.` (root direktori).
3. Klik **Deploy site**.

### 3. Cloudflare Pages / GitHub Pages
- Cukup aktifkan GitHub Pages melalui menu **Settings > Pages** di repositori GitHub, lalu pilih branch `main` pada root `/`.

### 4. Docker / Container
```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY . .
EXPOSE 3000
CMD ["node", "server.js"]
```
